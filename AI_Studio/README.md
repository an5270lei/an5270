# AI Studio - 第一阶段（真实聊天 API + 流式输出）

## 环境
- Windows 10/11
- Python 3.10+（实测 3.14 + PySide6 6.11 + openai 3.42 可用）
- PySide6 / openai / httpx

## 安装
```bash
python -m pip install -r requirements.txt
```

## 启动
```bash
python main.py
```

首次启动请点右上角「设置」→「聊天」页，填入 API Key 后保存。
Key 用 Windows DPAPI 加密存在 `%APPDATA%\AI Studio\secrets.dat`，
`config.json` 里只放地址、请求头、超时等非敏感项。

## 当前实现
- 真实 Chat Completions 接口，`stream=True` 逐字流式上屏
- 生成中按钮变「停止」，点击即中断（Event 标志，不用 terminate）
- 17 个模型全部在下拉框内，不可用的按实测结果灰显标注，随时可切
- 每条 AI 回复落库时记录实际使用的模型 ID 与状态（complete/stopped/error）
- SQLite 会话与历史（新增 `model` / `status` 两列，旧库自动迁移）
- 网络异常、超时、401/403/404/429/500 全部翻译成中文提示
- 聊天与生图配置分离，各自独立 API Key
- 上下文：最近 N 条消息窗口（默认 20）
- 白天 / 黑夜两套主题，顶栏一键切换并记住选择
- 正文栏最宽 780px 居中，窗口再宽也不会拉成长条
- **AI 自动判断是否生图**（Function Calling）：说「帮我画一张…」时模型自己
  调 `generate_image`，出图后自动接一段文字总结
- 生图走独立的生图 Key（聊天分组没有生图模型，实测 404）
- **画布尺寸只听设置**：模型无权指定 size（实测它会把 4K 悄悄写成
  1024x1024，服务端再返回 1254x1254），所以 tool schema 里没有 size 参数
- 尺寸/模型在「设置 → 生图」里选，4K 实测可用（2160x3840 直连返回原尺寸，
  单张约 100 秒）
- **尺寸下拉在输入框底行、发送按钮左边**，显示完整尺寸名
  （`4K 竖图 (2160x3840)`），改完立刻写 config、下一张生效；没开生图权限或
  没填生图 Key 时自动隐藏。键盘提示不再占用这一行，改成输入框悬停提示
- 图片落盘 `data/images/`，缩略图挂在气泡里，点击用系统看图打开；记录写入
  `images` 表（路径 / prompt / 模型 / 尺寸）
- 设置页「生图权限」可一键关掉自动生图（关掉后就是纯聊天）
- 设置页「测试出图」可独立验证生图 Key，不花对话次数
- **参考图改图**：输入框可附图片（最多 4 张），模型自己决定调 `edit_image`
  走 `images.edit` 改图；原图与结果都存库，历史里能看到「图 → 改后的图」
- **历史摘要**：消息数超过「窗口 + 8 条」后，后台把更早的部分压成 ≤300 字
  摘要塞进 system，增量更新（只压 `summary_until_message_id` 之后的新内容），
  不阻塞聊天；设置页可关
- 摘要实测：40 条历史压成 153 字，保留价格带、配色、屏数结论

## 模型可用性（2026-11-02 实测）
可用：`claude-opus-5-5` `claude-sonnet-5` `gpt-6-luna` `gpt-6-sol`
`gpt-6.1-sol` `gpt-5.6-luna` `gemini-3.8-flash`

其余 10 个在当前账号分组下 404 或连接后无响应，列表里保留但灰显。
分组权限变化后可直接选用，无需改代码。

### 工具调用（生图）能力
支持：`claude-sonnet-5` `claude-opus-5-5` `gpt-5.6-luna` `gpt-6-luna`
`gpt-6-sol` `gemini-3.8-flash`
不支持：`gpt-6.1-sol`（要 Responses API，本账号只有 Chat Completions）

两个坑已写进代码：
- `gpt-6` 系列和 `claude-opus-5-5` 挂 tools 时必须带 `reasoning_effort="none"`，
  否则要么 400，要么先说一句话就断；
- 模型不支持 tools 时引擎会自动摘掉工具重试，不会把 400 甩给用户。

注意：本网关首 token 延迟可达 14–28 秒，读取超时默认 120 秒。
生图单张约 37–60 秒，生图超时默认 300 秒。

## 生图怎么用
1. 「设置 → 生图」填生图 Key（必须是生图分组的 Key，和聊天 Key 不是同一把）；
2. 点「测试出图」验证一次（约 40 秒，会落一张图到 `data/images/`）；
3. 回到对话，直接说「帮我画一张…」，模型自己决定调不调；
4. 想关掉自动生图：「设置 → 聊天 → 生图权限」取消勾选。

## 改图怎么用
1. 输入框左侧「添加图片」选一张图（可多张，最多 4 张），缩略图会出现在输入框上方；
2. 写要求，比如「改成夜景，加霓虹灯，人物保持不变」，回车发送；
3. 模型判断后调 `edit_image`，走 `images.edit`，状态栏显示「正在改图 · N 秒」；
4. 原图和结果都进历史，点图可看原图。
